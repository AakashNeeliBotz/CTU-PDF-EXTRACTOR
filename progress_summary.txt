Project Progress Summary (CTU - Automated PDF Data Extraction and Consolidation)

Date: 2025-10-16

1) Environment & Dependencies
- Created requirements.txt and installed dependencies with uv (crawl4ai, httpx, pymupdf, pytesseract, pandas, openpyxl, apscheduler, camelot-py[base]).
- Verified local LLM setup via Ollama.

2) Configuration
- config.py initialized with base directories (downloads/, output/).
- OLLAMA_MODEL set to gemma3:4b; base URL http://localhost:11434.
- SOURCES populated with SN3–SN8 URLs; SN7 corrected to a direct HTTPS PDF link.

3) Crawling & Link Discovery
- scraper.py now tries Crawl4AI first for fully rendered pages, falls back to httpx with browser-like headers.
- Switched HTML parsing to BeautifulSoup and urljoin to resolve relative links robustly.
- Direct .pdf URLs are included immediately without HTML parsing.
- Added validation for non-.pdf links via HEAD/GET to confirm Content-Type 'pdf' or '%PDF' header before treating them as PDF links.
- Returns (pdf_url, referer_page) pairs for accurate downstream downloads.

4) Downloading PDFs
- downloader.py accepts (url, referer) pairs, sends desktop User-Agent and Referer headers.
- Validates payload before saving: requires Content-Type to include 'pdf' or bytes to start with '%PDF'.
- Skips non-PDF responses and logs reasons to prevent corrupt saves.

5) PDF Processing (Tables)
- pdf_processor.py switched to Camelot (stream flavor) for table extraction across all pages.
- Builds rows (dicts) from tables; uses first row as header when present or generic column names otherwise.
- Added logging for tables detected and skips.

6) Excel Output
- excel_handler.py writes to the second sheet (index 1) of the Connectivity Application Data.xlsx.
- Logs sheet name and number of rows written.

7) Orchestration & Logging
- main.py orchestrates crawl -> download -> extract -> write.
- Logging improved with timestamps and clear stage messages:
  - Start/end of crawl, number of links found
  - Start/end of downloads, number of PDFs saved
  - Rows extracted and whether Excel was updated

8) Current Behavior & Mitigations
- Many sites may serve HTML interstitials or viewer pages to scripted requests; downloader now avoids saving those as PDFs.
- Referer-aware requests and validation reduce the chance of corrupt files.
- Crawl4AI integration increases detection on dynamic pages; fallback ensures resilience.

9) Next Steps
- Add any additional SN3–SN8 URLs, then run the pipeline to validate end-to-end results.
- Map extracted table fields to the exact columns of the second sheet (schema alignment).
- Add OCR fallback (pytesseract) for scanned PDFs where Camelot fails.
- Introduce per-source header/cookie/session handling if any site blocks scripted downloads.
- Implement scheduling (APScheduler) for daily runs.
